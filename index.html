Routing Algorithms

Seven fundamental routing algorithms explained and visualized.

Algorithm 01

Shortest Path Routing (Dijkstra)

Finds the shortest path from a source router to all other routers using Dijkstra's algorithm.

How it works

  1. Initialize all router distances to infinity except the source (distance 0).
  2. Select the unvisited router with the smallest known distance.
  3. Relax all outgoing edges: if a shorter path is found, update the distance.
  4. Mark the router as visited and repeat until all routers are processed.

Algorithm 02

Flooding

Every incoming packet is sent out on all outgoing links except the one it arrived on.

How it works

  1. A source router sends the packet to all its neighbors.
  2. Each receiving router forwards the packet on all links except the incoming link.
  3. A hop counter (TTL) prevents packets from circulating forever.
  4. Every router in the network is guaranteed to receive the packet.

Algorithm 03

Distance Vector Routing

Routers periodically share their distance vectors with neighbors and update using Bellman-Ford.

How it works

  1. Each router maintains a distance vector with its best known cost to every destination.
  2. Routers exchange vectors with their direct neighbors periodically.
  3. On receiving a neighbor's vector, a router applies the Bellman-Ford equation: D(i,j) = min[D(i,j), c(i,k) + D(k,j)].
  4. Vectors converge to shortest paths after several rounds of exchange.

Algorithm 04

Link State Routing

Each router floods its link-state information, then computes shortest paths with Dijkstra.

How it works

  1. Each router discovers its neighbors and measures link costs.
  2. The router constructs a link-state packet (LSP) describing its links.
  3. LSPs are flooded to every other router in the network.
  4. Each router builds the full topology map and runs Dijkstra to find shortest paths.

Algorithm 05

Hierarchical Routing

Routers are organized into regions; routing happens at both intra-region and inter-region levels.

How it works

  1. Network is partitioned into regions, each managed by a designated router.
  2. Intra-region routing uses a standard algorithm within each region.
  3. Inter-region routing forwards packets between region gateways.
  4. This reduces the size of routing tables and control overhead in large networks.

Algorithm 06

Broadcast Routing

Delivers packets to every router in the network using flooding or a broadcast spanning tree.

How it works

  1. Flooding approach: each router forwards the packet on all links except the incoming one.
  2. Spanning tree approach: a tree is computed from the source so each router receives one copy.
  3. Reverse path forwarding checks if the packet arrived on the expected link before forwarding.
  4. Ensures all routers receive the broadcast while minimizing redundant traffic.

Algorithm 07

Multicast Routing

Packets are delivered to a specific group of routers using shared trees or source-based trees.

How it works

  1. Multicast group members register their interest in receiving packets for a group.
  2. Shared tree approach: a single tree rooted at a rendezvous point serves all sources.
  3. Source-based tree approach: a separate shortest-path tree is built per source.
  4. Packets traverse only the branches leading to group members, saving bandwidth.

About RouteLab-Simple

RouteLab-Simple is an educational simulator designed for students and enthusiasts of Computer Networks. It demonstrates seven fundamental routing algorithms through interactive visualization, helping you understand how packets traverse a network from source to destination.

The simulator uses Cytoscape.js for graph rendering and runs entirely in the browser with vanilla JavaScript. No backend, no build tools, no dependencies to install — just open index.html and start exploring.

Routing Algorithms Covered

  • Shortest Path (Dijkstra) — least-cost path computation
  • Flooding — packet diffusion to all nodes
  • Distance Vector — distributed Bellman-Ford
  • Link State — full topology with Dijkstra
  • Hierarchical — multi-level region routing
  • Broadcast — network-wide delivery
  • Multicast — group-targeted delivery

Technology Stack

  • HTML5 & CSS3
  • Vanilla JavaScript (ES6+)
  • Cytoscape.js (graph visualization via CDN)
